# Rohan Nath Portfolio

A personal portfolio website showcasing my research, publications, gallery, and contact information.

## Structure

- `index.html` - page content and semantic structure
- `assets/css/styles.css` - visual system, layout, and responsive styling
- `assets/js/main.js` - navigation, theme, scroll, gallery lightbox, and contact interactions
- `assets/js/bio-canvas.js` - theme-aware scientific background canvas
- `images/` - portrait and favicon assets
- `images/gallery/` - gallery JPEG/WebP image pairs

## Image Updates

- Use descriptive gallery filenames, for example `images/gallery/rupin-pass.jpg` and `images/gallery/rupin-pass.webp`.
- Add the newest gallery card first in `index.html` inside `#galleryTrack`; the page displays cards in markup order.
- Keep a JPEG fallback for every WebP image by using the existing `<picture>` pattern.

## Run Locally

Open `index.html` in a browser. No build step is required.
